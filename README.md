# FO4-SaveNameFix

Отдельный патч Fallout 4. К радио [Jah Bless](https://github.com/ShamanOrWhitch/Jah-Bless) не относится.

После обновления игра пишет сейвы так:

`Exitsave0_00000000SM4A4168436F7265_Commonwealth_....fos`

В русской локализации лаунчер из-за хвоста `SM` не запускается, пока буквы и цифры не стереть руками. Патч обрезает формат в `Fallout4.exe` до номера слота:

`Exitsave0.fos`, `Autosave2.fos`, `Save1.fos`

Проверено на версии **1.11.240.0**. Ищется сама строка формата, не адрес. Если в новом обновлении строки больше нет, файл не меняется.

## Как поставить

1. Закрой игру.
2. Перетащи `Fallout4.exe` на `Patch-SaveName.bat`.
3. Рядом появится `Fallout4.exe.bak`.
4. Старые файлы с `SM` в папке Saves переименуй один раз. Новые уже короткие.

Steam при проверке файлов вернёт оригинальный exe. Тогда перетащи его на bat ещё раз. Jah Bless из-за этого обновлять не нужно.
